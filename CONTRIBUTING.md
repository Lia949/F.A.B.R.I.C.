# Contributing to F.A.B.R.I.C
First of all, thank you for considering contributing to F.A.B.R.I.C! There are many ways to help and I appreciate everyone doing that. Here are some examples for ways to help:
- report typos/errors/inconsistencies in the rules
- report weird formatting in the online wiki
- discuss the current state
- propose new features
- propose a change in the basic structure of the framework - there is always potential to make things more elegant
- create a system/setting/oneshot
- design charactersheets

# How to get in contact
To start contributing open a new issue or pull request with your topic. Also feel free to send a mail to fabric_rpg@proton.me if you have any questions.

# Any contributions you make will fall under CC BY-NC 4.0
In short, when you submit rule changes and ideas, your submissions are understood to be under the same License that covers the project. Feel free to contact me if that's a concern.
